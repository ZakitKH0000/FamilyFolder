# Снимки для русской карточки Microsoft Store

Замените английские снимки в карточке «Русский» этими PNG, в указанном порядке. В английской карточке сохраните английские изображения. Переписка и устройства демонстрационные.

| Файл | Подпись |
|---|---|
| 1-papych.png | Знакомьтесь, Папыч: доставляет файлы брату бумажными самолётиками. |
| 2-shade.png | Потащите файлы к верху экрана: на Папыча — всем, на робота участника — только ему. |
| 3-tour.png | Папыч выпрыгивает из окна и знакомит с возможностями приложения. |
| 4-window.png | Входящие файлы, чат с голосовыми и настройки уведомлений. |
| 5-moods.png | Папыч здоровается, чихает, кружится, спит на паузе и ищет связь. |
| 6-chats.png | Ответьте текстом или голосом прямо из шторки сверху экрана. |
| 7-voice.png | Голосовые сообщения с волной звука и анимациями Папыча. |
| 8-cloud.png | Зашифрованные сообщения ждут получателя в вашем облаке. |

Первые пять — русский комплект прежних сцен, но окно приложения показывает актуальную 1.5.0: файлы, полноценный чат и настройки звука. Остальные три — мини-чат, голосовые и облачная доставка. Размеры: 1440×810 либо 1920×1080. PNG.

| 9-explorer.png | Управляйте общей папкой через панель рядом с Проводником. |

Обновление: 2/3/6 — без непрозрачного прямоугольного canvas вокруг шторки и экскурсии; шторка показана компактнее. 9 — стилизованный Проводник и настоящий интерфейс панели, демонстрационные файлы.
